# P0-2 任务拆分清单

> 难度：1 = 照抄模板 / 2 = 有明确规格的常规代码 / 3 = 需要领域知识 / 4 = 正确性核心 / 5 = 架构级难点
> 预估：以"有效工作小时"计（agent 实际执行时间加上审查时间），不含等待。
> 分工原则：**难度 ≥4，以及所有涉及"结果是否可信"的代码归 Cen**；难度 ≤3、规格能写死的归 Bob。Bob 的每份产出都由 Cen 审查后才合并。
> 合计：Cen ≈ 87h（26 项），Bob ≈ 84h（34 项），两人合做 1 项（P2-18），另有 24h 实跑等待。按**任务数**算，约 56% 交给 Bob；工时接近是因为 Cen 的工时集中在引擎、PIT、撮合这些"决定结果是否可信"的硬代码上，这部分不能下放。凡是能写死规格的活都已经拆给 Bob。
