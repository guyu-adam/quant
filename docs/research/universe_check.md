## 定期调整抽查

抽查中分别保留沪深 300 和中证 500 的调入、调出；“在/不在”以 Baostock 对应调整后月末响应为准。2008 指定的 `2008-06-30` 早于该次公告规定的生效时间：上交所公告称调整于 2008 年 7 月第一个交易日生效。因此该月末必然仍是调整前名单，另外列出真正生效后的 `2008-07-31` 检查结果，避免把公告日误认为生效日。

2008 与 2015 的逐项名单由相邻月末 Baostock 快照差集计算；官方公告用于确认该期确有定期调整，2015 的具体名单还可在上交所附件复核。2008 的 `2008-06-30` 快照对 7 月生效的调入股（如 `sh.601390`）仍显示不在，调出股（如 `sh.600035`）仍显示在；改用调整生效后的 7 月月末后，上表所列调入、调出校验通过。

2021 调整公告称沪深 300、中证 500 等指数在 2021-12-10 收市后生效。可是 Baostock 对 `2021-12-31` 返回的沪深 300 与 `2021-11-30` 完全相同，所有成员 `updateDate` 都为 `2021-11-15`；无法用该接口证明调整后的名单。该项核对因此标为未通过/数据源缺口，不虚构成分变更或把新闻摘要当成完整名单。复查建议由 Cen 使用中证指数公告的完整名单或另一历史成分源补录并验证。

## 复现

```bash
uv run python scripts/build_universe.py --start 2005-01 --end 2026-09 --out /tmp/q6uni/universe_monthly.parquet
uv run python -c "import pandas as pd; d=pd.read_parquet('/tmp/q6uni/universe_monthly.parquet'); print(d.groupby(d.month_end.dt.year).code.nunique()); print('union', d.code.nunique(), 'months', d.month_end.nunique())"
```
